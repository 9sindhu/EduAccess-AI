# EduAccess AI – AI-Powered Educational Accessibility Platform

EduAccess AI is a web-based platform designed to make educational content more accessible, inclusive, and easier to understand. It helps students interact with educational materials through features such as multilingual content support and accessibility options, making learning more convenient for students with diverse learning needs.

## 🚀 Features

- **Educational Document Upload:** Upload educational documents and process their content for easier access.
- **Multilingual Support:** Access educational content in different languages.
- **Accessibility Options:** Apply accessibility features to improve the readability and usability of educational content.
- **Text-Based Content Processing:** Enter or paste educational text and use available accessibility options.
- **User-Friendly Interface:** A simple, responsive interface designed to make educational resources easier to access.
- **Backend Integration:** A Node.js backend supports the application's document-processing and related functionality.

## ⚙️ Installation and Setup

### Prerequisites
- Node.js and npm installed
- Git installed
- A code editor such as Visual Studio Code

### 1. Clone the repository

```bash
git clone https://github.com/9sindhu/EduAccess-AI.git
cd EduAccess-AI
```

### 2. Install backend dependencies

Navigate to the backend directory (if your project uses one):

```bash
cd backend
npm install
```

### 3. Start the backend server

```bash
npm start
```

If your project uses a development script, you can run:

```bash
npm run dev
```

### 4. Open the frontend

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

Make sure the backend server is running whenever the frontend requires backend API functionality.

## 💡 How It Works

1. Open the EduAccess AI website.
2. Paste educational text or upload an educational document.
3. Select the desired language or accessibility option.
4. Process the content using the available features.
5. Read the resulting content in the selected format or language.
